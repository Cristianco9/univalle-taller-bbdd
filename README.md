## 📌 Descripción General

Este proyecto consiste en el diseño e implementación de una **base de datos relacional  ara un sistema bancario** llamado **BancoSeguro**.  

El sistema permite gestionar clientes, cuentas bancarias, transacciones, empleados, 
sucursales, préstamos y tarjetas, aplicando conceptos fundamentales de **modelado 
de datos**, **DDL** y **DML**.

El proyecto fue desarrollado como parte académica de la asignatura **Bases de Datos**.

---

## 🎯 Objetivos

- Diseñar una base de datos relacional completa
- Aplicar comandos **DDL** (CREATE, ALTER, DROP)
- Aplicar comandos **DML** (INSERT, SELECT, UPDATE, DELETE)
- Implementar restricciones de integridad
- Realizar consultas SQL básicas, intermedias y avanzadas
- Simular operaciones bancarias reales
